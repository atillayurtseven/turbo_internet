Privacy Policy

Turbo Internet Download Manager · last updated 8 September 2026

This extension collects nothing, sends nothing anywhere, and has no server behind it. Everything it does happens inside your own browser.

What is stored, and where

  • Your settings — rules, connection counts, language and similar preferences. Kept in Chrome's own extension storage, which syncs through your Google account if you have Chrome sync enabled.
  • Your download list — file names, sizes, progress and source addresses of downloads you started. Kept locally on the device.
  • Parts of a file being downloaded — held in the browser's private storage until the finished file is written to disk, then deleted.

None of this leaves your device. There is no account, no analytics, no telemetry, no crash reporting and no third-party service of any kind.

What the extension looks at

Network requests on pages you visit

To offer a video for download, the extension needs to notice that a page is playing one. It watches the addresses and content types of requests made by pages you visit, in memory, to spot media. It does not read page content, form input, or anything you type. What it finds is listed in the popup for that tab and is discarded when you navigate away, after ten minutes, or when you clear the list.

Downloads

When a download is taken over, the file is fetched directly from the site hosting it to your browser. The request carries the cookies and referrer your browser would normally send, so files behind a login work as expected. Nothing is proxied through us; we never see the file or the address.

Copied links (off by default)

If you switch on Watch copied links, the extension notices when you copy text on a page and, only when that text is a short http or https address, offers it in the popup as something you might want to download. Anything else you copy is ignored and never leaves the page. The setting is off unless you turn it on, and the suggestion is kept in memory only.

Permissions, and why each is needed

  • downloads — to take a download over from Chrome and to save the finished file. This is the only way an extension can write a file to disk.
  • storage, unlimitedStorage — to keep your settings and to hold the parts of a large file while it downloads.
  • offscreen — the download engine runs in a hidden document, because a service worker is stopped after a few seconds of inactivity.
  • scripting — to show the "download this with…" card inside the page you are on.
  • webRequest — to notice media on the page, as described above. It only observes; it never blocks or alters your browsing.
  • tabs — to know which tab a download belongs to and to name a stream after the page it came from.
  • contextMenus — for the right-click "download with" entry.
  • declarativeNetRequestWithHostAccess — to set the referrer on the extension's own download requests, which some servers require.
  • Access to all sites — a download can come from any site, so the extension cannot know in advance which ones it will need.

Children

The extension is not directed at children and collects no personal information from anyone.
