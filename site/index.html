Turbo Internet Download Manager

Chrome extension · by TurboInternet

Downloads a file over several connections at once, picks up where it left off, and tells you exactly what it saved.

What it does

  • Parallel downloading. Where the server allows ranged requests, a file is split and fetched over several connections. A connection that finishes early takes over part of a slower one.
  • Rules per file type. Decide which extensions are taken over, how many connections each gets, a minimum size, and a subfolder.
  • It asks first. By default a card appears in the page before anything is taken over. Say no and Chrome keeps the download.
  • Streams. HLS playlists found on a page can be downloaded and converted to a plain, seekable MP4. Nothing is re-encoded.
  • Verification. Every part is size-checked before the file is assembled, and an optional SHA-256 lets you compare against a published checksum.
  • Resume and rate limiting. Pause, resume, cap the speed.

What it will not do

YouTube and comparable platforms are out of scope. Downloading from them breaks their terms of service, and Chrome Web Store policy forbids extensions that do it.

Install

A Chrome Web Store listing is on the way. Until then the extension can be loaded from source: open chrome://extensions, turn on Developer mode, choose Load unpacked and select the extension folder.

Privacy in one line

Nothing is collected and nothing is sent to us — there is no server behind this extension. Read the full policy.
